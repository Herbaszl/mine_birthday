# 🎂 Meu Aniversário: Convite Digital Interativo 🥳

Bem-vindo(a) ao repositório do **Meu Aniversário**! 🎁 Este projeto é uma **landing page de evento** moderna e interativa, que serve como um convite digital personalizado para uma celebração especial. Desenvolvido com as tecnologias web mais atuais, ele oferece uma experiência fluida e envolvente para os convidados, incluindo um **contador regressivo**, **marcador de presenças (RSVP)** e **animações elegantes**.

---

## ✨ Recursos Principais

Este convite digital foi pensado para ser completo e intuitivo:

* **Contador Regressivo:** Mantenha os convidados ansiosos com uma contagem regressiva precisa até o grande dia.
* **Marcador de Presenças (RSVP):** Funcionalidade para os convidados confirmarem sua presença, facilitando a organização do evento.
* **Animações Suaves:** Elementos visuais que aparecem elegantemente na tela, proporcionando uma experiência de usuário agradável e dinâmica.
* **Design Responsivo:** Layout adaptável para dispositivos móveis e desktops, garantindo que o convite seja perfeito em qualquer tela.

---

## 💻 Tecnologias Utilizadas

Para construir um convite tão dinâmico e fluído, foram utilizadas ferramentas poderosas e eficientes:

* **HTML:** A estrutura sólida e semântica da nossa landing page. 🧱
* **SCSS (Sass):** Nosso pré-processador CSS favorito, permitindo uma estilização modular, elegante e fácil de manter. 🎨
* **JavaScript:** A inteligência por trás da interatividade, controle do contador e da lógica do RSVP. ⚡
* **React.js:** Utilizado para criar uma interface de usuário fluida e reativa, otimizando o desempenho e a experiência do usuário. Componentes reutilizáveis tornam o desenvolvimento mais rápido e eficiente. ⚛️
* **AOS (Animate On Scroll) JavaScript Library:** Responsável pelas belas animações de elementos que surgem na tela conforme o usuário rola a página, adicionando um toque de magia e profissionalismo. ✨
